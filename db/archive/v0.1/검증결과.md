# SQL 검증 결과

검증일: 2026-10-19

## 완료

- pglast 8.7의 PostgreSQL 파서로 `001_schema.sql`의 60개 SQL 문과 `002_smoke_test.sql`의 4개 SQL 문을 구문 분석했다. 모두 통과했다.
- 함수 및 DO 블록의 PL/pgSQL 본문도 별도 파싱하여 통과했다.
- 생성 대상은 테이블 31개, 조회 뷰 3개다.
- 문서 검토 중 영업일의 종료 시각 NULL이 CHECK를 통과할 수 있는 부분을 수정했다.

## 미실행

현재 환경에 psql·postgres·Docker 실행 도구가 확인되지 않아 실제 PostgreSQL에 적용하지 않았다. 파싱 성공은 외래키·확장 설치·제약 실행·권한·동시 처리의 성공을 보장하지 않는다.

`002_smoke_test.sql`은 개발 DB에 스키마를 적용한 후 실행할 테스트다. 중복 방문 거절, 정확히 2시간인 시점 제외, 2시간 후 인접 방문 허용, PT 시간 겹침 거절, 연속 시간 예약 허용, 초과 확보 거절, 이력 변경 거절을 검사한다. 테스트 데이터는 ROLLBACK하지만 ID 시퀀스의 사용 번호는 복원되지 않을 수 있다. 운영 DB에서 실행하지 않는다.

실제 동시 연결을 이용한 경쟁 조건 테스트, 24시간 취소·보상·휴회·알림·접근 권한 검증은 서비스 트랜잭션 구현 후 별도로 필요하다. 테스트용 정책은 DRAFT이며 이는 스키마 제약 테스트를 위한 값이다. 실제 예약 서비스는 승인 정책만 사용하도록 검증해야 한다.

## 재현

`db/validate_sql.py`는 프로젝트의 `.validation`에 설치한 pglast를 사용한다. 이 의존성 폴더는 버전 관리에서 제외했다. 이 도구는 문법 확인용이며 앱 실행 의존성은 아니다.
