# 2026-11-11 · 예약하기·내 예약·마이페이지 디자인 일괄 확인

사용자 요청에 따라 세 화면을 웜 웰니스 스타일로 함께 구현했다. 예시 데이터를 사용하는 디자인 검토 단계이며 실제 예약·회원정보 변경·서버 호출은 하지 않는다.

| 화면 | 확인할 내용 |
|---|---|
| 예약하기 | 담당 트레이너·예약 가능 횟수·현재/다음 달 달력·공개 시간·예약 확인 |
| 내 예약 | 예정/지난 예약·상세·일정 변경·취소 확인·완료 일지 |
| 마이페이지 | 회원정보·시설/PT 이용권·휴회 안내·일지·소식·알림함·알림 설정·계정 메뉴 |

앱을 다시 불러온 뒤 예약/마이페이지 탭에서 확인한다. 예약하기에서 날짜와 시간을 선택하고 `예약 내용 확인 → 미리보기 예약하기`를 누르면 내 예약 목록에 예시 일정이 추가된다. 일정 변경은 원래 예약을 확인 전까지 유지하고, 취소 확인 화면에서 확보 해제/늦은 취소 차감을 구분한다. 실제 수업을 등록하거나 취소하지 않는다.

예약 확보 횟수는 예약하기·내 예약·마이페이지에 함께 반영된다. 홈의 다음 예약도 같은 예시 목록을 사용한다. 화면 이동 후에도 예시 변경은 유지하고 앱 재시작/웹 새로고침 시 초기화한다. 과거·마감·내 예약·이용권 유효기간 밖의 시간은 선택할 수 없다. 알림 읽음·설정 스위치도 이 앱 세션의 미리보기 상태다.

마이페이지의 회원정보/이용권/일지/소식/알림은 상세 안내를 연다. 휴회는 내역·신청 안내까지만 제공하며 실제 신청 폼/접수는 후속이다. 비밀번호 변경·로그아웃·탈퇴는 디자인 안내이며 실제 인증 상태 변경이나 탈퇴 접수/삭제를 수행하지 않는다. 보안 정보 입력은 받지 않는다.

검증: 타입 검사, 달력 시험 5개·예약 상태 시험 7개, 웹·Android/iOS JS export(`--no-bytecode`) 통과. 브라우저에서 예시 예약 추가→일정 변경→취소, 확보 횟수 2→3→2와 예약 가능 6→5→6 동기화, 다음 달 이동·유효기간 제한·공개 시간 없음, PT 이용권에서 내 예약 진입, 알림 설정 스위치, 일지·소식·탈퇴 안내, 320px 시간 선택/확인 화면과 고정 하단 메뉴를 확인했다. 실기기 전체 화면 확인은 사용자 피드백을 기다린다.

주요 코드: `src/screens/BookingScreen.tsx`, `src/screens/MyPageScreen.tsx`. 공통 UI는 `src/components/MemberPage.tsx`, `DetailSheet.tsx`, `memberStyles.ts`; 예시 예약 상태는 `src/state/BookingPreviewContext.tsx`와 `src/utils/bookingPreview.ts`에 둔다. 새 라이브러리는 설치하지 않았다.

# 웜 웰니스 · React Native 회원 홈

2026-11-02. Figma **03 웜 웰니스** 홈 화면 하나를 확인하는 Expo/React Native 앱이다. 표시된 인원·이용권·출석·예약은 고정 예시 데이터이며 현재 날짜나 실제 회원정보가 아니다.

## 바로 확인

현재 브라우저 미리보기: [홈 화면](http://127.0.0.1:8091). React Native 코드를 React Native Web으로 렌더링한 동일 화면이며 기존 Spring Boot의 8080 웹 화면과 별개다.

실제 휴대전화에서 확인하려면 이 폴더의 터미널에서:

```cmd
npm start
```

PC와 휴대전화를 같은 Wi-Fi에 연결하고 **Expo Go**로 터미널의 QR을 연다. Android는 Expo Go 안에서 QR을 스캔하고, iPhone은 카메라로 QR을 연다. 현재 package.json의 Expo SDK 58과 호환되는 실행 앱을 사용한다. 화면의 입장 QR 버튼과 터미널의 Expo 실행 QR은 용도가 다르다.

이 미리보기에는 Spring Boot·PostgreSQL 실행이나 로그인이 필요 없다. 앱이 연결되지 않으면 PC/휴대전화의 Wi-Fi가 같은지와 개발 도구의 로컬 네트워크 접근 허용 상태를 확인한다. 방화벽 전체를 끄지 않는다.

## 실행·종료

```cmd
cd mobile
npm install        # 현재 PC에는 설치 완료. 다른 PC/새 체크아웃에서 실행.
npm start          # Expo Go 확인, 개발 서버 8081
npm run web        # 같은 React Native 화면의 웹 개발 미리보기, 8081
```

`npm start`와 `npm run web`는 한 번에 하나만 실행한다. 실행한 터미널에서 **Ctrl+C**로 종료한다. 창을 닫는 대신 Ctrl+C를 사용한다. 현재 Codex가 열어 둔 별도 미리보기(8091)를 끄고 싶으면 이 채팅에서 종료를 요청할 수 있다.

웹 정적 미리보기를 직접 다시 켜려면:

```cmd
npm run export:web
npm run preview:web  # 127.0.0.1:8091, 실행 터미널의 Ctrl+C로 종료
```
