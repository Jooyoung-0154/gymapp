# 웜 웰니스 홈 구현 기록

범위: 사용자 요청에 따라 React Native 회원 홈 한 화면만 구현. 서버 연결·다른 화면·기존 Spring Boot 수정 없음.

기준: Figma `3HZCxZiuoQO7anXoSg3Yw6`, `03 웜 웰니스`의 홈 `9:1631`. Figma 파일은 읽기만 수행했다. 디자인 컨텍스트와 원본 아이콘을 내려받아 React Native View/Text/Pressable/ScrollView로 옮겼다.

색: 배경 #FAF5ED, 카드 #FFFCF7, 혼잡도 #F1DED0, 포인트 #AC5137, 본문 #3E302A. 카드 24px·혼잡도 28px·버튼 pill, 바깥 여백 20px·카드 간격 16px. 글꼴 Noto Sans KR 400/500/700, 숫자 Inter 500. `mobile/src/theme/warmWellness.ts`가 공통 기준이다.

홈 카드 순서와 표본 숫자를 유지한다. 접근성/오인 방지를 위해 작은 안내를 12px로 보강하고 혼잡도에 `입장 후 2시간 기준 추정 · 예시`를 명시했다. 상세/다른 메뉴 진입은 미리보기 안내만 표시한다. 다른 화면을 구현한 것처럼 처리하지 않는다.

실행 파일: `mobile/App.tsx`. 예시 데이터: `mobile/src/data/homePreview.ts`. Expo Go 개발 서버 8081, 정적 브라우저 미리보기 8091. 실기기는 사용자가 같은 Wi-Fi에서 Expo Go로 확인해야 하며 자동 실기기 확인 완료로 기록하지 않는다.

검증: 타입 검사, Expo 호환 검사, Android/iOS/웹 번들, 390px/320px 웹 배치·스크롤·버튼 점검 통과. 상세와 실행/종료 방법은 `mobile/README.md`에 기록했다.
